# Ícone

Ferramenta: image_gen incorporada; nenhuma chave de API utilizada.
Arquivo final: ../plugin/assets/icon.png
Uso: logo do catálogo e ícone do composer.

Prompt: Create a final professional app icon for Brasil Notícias, a serious Brazilian news plugin with an inline newspaper bulletin. Square 1024x1024 PNG icon. Restrained editorial visual identity: deep navy blue #122638 solid square background, one bold ivory folded newspaper silhouette centered, with three strong horizontal editorial lines and one small muted gold #b29a61 rectangular accent. Flat graphic, crisp simple geometric edges, distinctive legible silhouette at 48 pixels, generous safe margins. No letters, no text, no flag, no globe, no borrowed broadcaster logos, no gradient, no 3D, no shadows, no watermark. Asset use: public plugin directory listing and composer icon.

Imagem produzida e inspecionada. A versão original contém fundo próprio azul escuro e funciona como bloco contrastante em interfaces claras e escuras. Nenhuma variação de modo escuro é necessária para esta versão; preferências adicionais permanecem opcionais.
