# Segurança

Para problemas envolvendo dados ou credenciais, escreva para sidvandoni@gmail.com. Não exponha a falha com dados sensíveis em uma issue pública.

O servidor restringe domínios e redirecionamentos, não encaminha cookies do usuário aos veículos e não executa instruções recebidas em notícias. A interface usa texto de fontes como texto, sem inserir HTML externo. As instruções do modelo exigem atribuição e declaração de evidência insuficiente; não constituem garantia absoluta contra erros de um modelo.
