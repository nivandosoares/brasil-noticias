# Contribuições

Abra uma issue para relatar erros ou sugerir fontes. Inclua comportamento esperado, resultado observado e link público da matéria quando pertinente. Não envie conversas privadas ou credenciais.

Para mudanças, crie uma branch, execute `node scripts/build.mjs`, `node scripts/release-tests.mjs` e `node scripts/validate-artifact.mjs`, e abra um pull request. Novas fontes devem ter identidade editorial verificável, URLs restritas e limitações de acesso documentadas. Não acrescente notas automáticas de “confiabilidade” ou contorno de paywalls.

Use SemVer e registre mudanças no CHANGELOG. Recursos novos vão em versão minor; correções compatíveis em patch. Uma release de código não equivale à aprovação do plugin no diretório.
